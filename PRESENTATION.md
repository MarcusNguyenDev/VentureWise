# VentureWise — Hackathon Presentation Brief

**A behavioural interview coach for international students job-hunting in Australia.**

> One line, no slide: *"Every interview coach on the market was built for someone who grew up here. Watch what happens when the person interviewing isn't."*

---

## 1. The pitch in 30 seconds

Every interview-prep tool on the market coaches a domestic candidate. An international student walks into the same room carrying three extra problems that no product addresses:

| Gap | The problem | What we built |
| --- | --- | --- |
| **The pronoun problem** | Collectivist cultures teach that claiming individual credit is rude. Australian interviewers read *"we redesigned the pipeline"* as **no evidence you did anything**. | A live **I/We meter** that moves while you talk, plus a first-person rewrite with a word-level diff. |
| **Accent-penalising scoring** | Delivery scorers were tuned on native speakers. L2 prosody gets marked down for word-retrieval pauses — a fluency artefact, not a competence signal. | An **accent-fair delivery score** that publishes, in the UI, the list of things it refuses to grade. |
| **The sponsorship question** | *"Will you require sponsorship?"* ends interviews. The entire internet's answer is a blog post saying "answer honestly." | A **30-second timed drill** with the subclass 485 arithmetic already done. |

**The competitive map:** the category splits into tools that grade *what you say* (Big Interview, CleverPrep) and tools that grade *how you say it* (Yoodli). Nobody has joined them, and **nobody at all has touched the third column** — the intercultural and sponsorship layer.

## 2. The demo script (90 seconds)

| Mark | Beat |
| --- | --- |
| **0:00** | One line, no slide. |
| **0:10** | Pick a career track — the CV and posting fill in. Three-round plan renders. **Do not narrate it.** |
| **0:25** | **Take one.** Answer the disagreement question naturally. I/We meter sits at 1:6, goes red. Let the room watch it move. |
| **0:50** | Answer ends. **First-person rewrite diff** — same story, six verbs reclaimed. This is the emotional beat. |
| **1:05** | **Take two.** Ten seconds only. Meter climbs to 4:1, STAR bar reaches Result. Cut it off early. |
| **1:15** | **The closer.** Sponsorship drill. Timer counts down from 30. The answer lands in 19 seconds. Stop talking. |

**Insurance:** a canned transcript replay drives the same buffer as the live mic. It is a first-class option in the UI, not a debug flag — and it supplies *real word timings*, so the pause coaching is only fully demonstrable in that mode. Venue wifi cannot kill the demo.

## 3. Architecture — three loops at three clock speeds

**The mistake that kills this demo is putting a language model in the sub-second path.** A nudge that lands four seconds late is worse than no nudge. So feedback is split into three loops:

| Loop | Budget | Where | What it does |
| --- | --- | --- | --- |
| **Fast** | `< 120 ms` | Browser, **no network** | I/We meter, live "we" highlighting, rolling pace, hedge + filler match |
| **Mid** | `~ 800 ms` | API, every 6–8 s of speech | STAR stage + durations, quantified-result check, **at most one nudge** |
| **Slow** | on stop | API, once | First-person rewrite + diff, subtext decode, delivery score |

```
[ Streaming ASR ] → [ Transcript buffer ] → [ Cached prefix ] → [ Single nudge slot ]
```

- **Append-only transcript buffer.** One store; all three loops read from it. State is never re-derived per loop.
- **Cached prompt prefix.** Resume + posting sit in a stable prefix so mid-loop calls send only new speech. Measured at ~1,094 tokens — clears the 1024-token caching threshold, but only just.
- **Single nudge slot,** 4-second minimum dwell, enforced in `session.service.ts` *and* again in the browser. Competing nudges are how this feels broken.

### The fast loop is generated, not duplicated

The same maths has to run in the browser and on the server. The API is the source of truth; [`front-end/lib/fast_loop/`](front-end/lib/fast_loop/) is regenerated by [`scripts/sync_fast_loop.sh`](scripts/sync_fast_loop.sh), with a `--check` mode that fails when stale.

## 4. The AI boundary — the design decision to lead with

**Every model-backed capability sits behind one interface**, `AiCoachPort` in [`api/src/ai_coach/ai_coach.contract.ts`](api/src/ai_coach/ai_coach.contract.ts). Nothing else in the codebase mentions a model, a prompt, or a vendor. Swapping providers is a one-file change.

Five methods, split by tier:

| Method | Tier | When |
| --- | --- | --- |
| `trackAnswerProgress` | mid loop | Every 6–8 s of speech |
| `critiqueAnswer` | slow loop | On stop |
| `decodeSubtext` | slow loop | On stop, parallel with critique |
| `extractStoryFromMemory` | slow loop | Off path — multilingual in, STAR out |
| `buildInterviewPlan` | slow loop | Off path — resume + posting in, gaps out |

**Every fixture result carries `is_stubbed: true` and the UI badges it "Awaiting AI."** Nothing placeholder can be mistaken for real output on stage — including when a model call times out and falls back.

### Measured cost: ~$0.0096 per 5-minute session

The spec budgeted $0.33. Real measured numbers from inside the dev container, priced from **measured output tokens, not headline rates**:

| Model | $/call cached | Output tok | Latency | |
| --- | --- | --- | --- | --- |
| `gpt-4.1-nano` | **$0.000030** | 21–33 | ~0.9 s | **Bound to the mid loop** |
| `gpt-5.6-luna` | $0.000139 | 102–138 | ~2–3.5 s | **Bound to the slow loop** |
| `gpt-5-nano` | $0.000518 | **1,285** | ~11.6 s | The trap — cheapest rates, ~17x the real cost |

**`gpt-5-nano` is the story worth telling:** the lowest published rates of anything tested, and dearest in practice, because it spends over a thousand reasoning tokens per call. Always price a candidate from a measured call.

**Also worth telling:** every model tested wavered between `TASK` and `ACTION` on the same transcript, and the pricier models were no better. The distinction is genuinely ambiguous mid-answer, so it is solved with a deterministic prior (`star_stage_estimation.util.ts`) that the model confirms — **not by buying a bigger model.**

## 6. The positioning decisions — what to say when judges probe

These are the answers that separate this from a weekend CRUD app. Each one is a place where the easy build was rejected on principle.

### It detects patterns in text. It does not classify the speaker.

First-language carry-over detection quotes back the grammatical patterns a first language leaves in spoken English — missing articles, unmarked plurals, dropped third-person `-s` — with a fix.

- Output is always *"here is a sentence you said and how it will land"*, never *"you are probably from X"*. Inferring nationality from speech is the inference this product exists to argue against, and in anything adjacent to hiring it is legally fraught in Australia.
- **First language is asked, not inferred.** An optional setup field feeds the prompts, which are explicitly told not to guess when it is absent.
- **None of it is scored.** `NOT_SCORED_BY_DESIGN` promises second-language grammar is not graded; this produces coaching only.

**The accuracy ceiling, stated honestly:** speech recognisers are language-model-smoothed — they insert articles and plural endings the speaker did not say. Carry-overs are therefore **under-detected** from a live mic. Detections are real; non-detections are not evidence, and the UI says so. Verified across three transcripts: a fluent answer produced **0 false positives**, a carry-over-heavy answer produced 7 correct detections, a mixed-but-clean answer produced 0.

### The camera is a mirror, not a mark

Spec Part 8 cut video scoring outright, because it fails on conference-room webcams and it is the one thing that can visibly break on stage. It was built anyway — under three constraints:

1. **It never enters the delivery score.** The reading sits beside it, labelled *not scored*. If it is ever folded in, two lines of `NOT_SCORED_BY_DESIGN` become false.
2. **No emotion classification.** Inferring emotional state from a face is scientifically contested. What is derived is observable: gaze steadiness, head steadiness, face-visible fraction, blink rate, brief upper-face movement rate. The UI names movements — "brow furrow", "lip press" — never moods.
3. **Gaze *steadiness*, never gaze *direction*.** Eye contact is a cultural norm; scoring it would punish exactly the behaviour this product exists to help someone navigate.

**Graded harshly on purpose** — a mock that flatters you teaches nothing. Calibrated against synthetic profiles: near-perfect 94 (Composed), good 79 (Steady), ordinary nervous 47 (Restless), visibly rattled 15 (Very restless).

**The engineering detail worth mentioning:** brief facial movements last 40–200 ms, which sets the sampling floor. Switching from an 80 ms timer to `requestVideoFrameCallback` took recall on a 66 ms movement from **83% to 100%** over 20 randomised trials — with **zero** false positives on a resting face. Upper face only, because speech drives the mouth on every syllable and a mouth detector would just be measuring "is currently talking".

**Video never leaves the browser.** The wasm runtime and the 3.7 MB model are served from `public/mediapipe/` rather than a CDN — venue-wifi insurance. Only derived numbers cross the network: `CameraPresenceDto` carries fractions and rates, never a frame, landmark or image. The library is dynamically imported so camera-off users never download it.

The interviewer tile is an abstract silhouette, not a stock photo or a generated face — putting an invented person on screen and calling them your interviewer is a small dishonesty the product does not need.

### Honest about its own data

- Every employer sponsorship record is `is_verified: false`, the API sets `must_verify_before_use`, and the UI shows a red warning. **A candidate says this out loud to a recruiter who works there.**
- The subclass 485 stream names and durations have changed more than once recently and need verifying against immi.homeaffairs.gov.au before anyone relies on the arithmetic.
- Ships a permanent **"Not migration advice"** banner — in Australia only a MARA-registered migration agent or a legal practitioner may give it.

## 7. Market: localised from the US to Australia

The spec was written for the US. The pivot was not a find-and-replace — the underlying immigration system is structurally different:

| | United States (spec) | Australia (built) |
| --- | --- | --- |
| Student work rights | Unlimited on-campus, capped off | **Subclass 500** — 48 hours a fortnight in session |
| Post-study work | OPT, 12 months | **Subclass 485** — 18 months to 3 years |
| What extends it | STEM designation | **Qualification level**, plus regional study |
| Employer sponsorship | H-1B, annual cap, March lottery | **Subclass 482** — no cap, no ballot, lodge any time |
| Employer signal | E-Verify enrolment | **Approved / accredited sponsor** status |
| Who advises | DSO | **MARA-registered migration agent** |

**The Australian answer is structurally stronger, and the product says so:** no cap, no ballot, no once-a-year filing window — which removes the objection the recruiter is bracing for. Almost no candidate knows to say it.

**The cultural layer is specific without being about one country.** The recurring theme across 27 hand-written intercultural notes: conversational courtesy in much of the world — deferring credit, softening claims, minimising your contribution before it is judged — is read by Australian interviewers as an *absence of evidence* rather than as good manners. The notes describe communication norms, not people, and never say one norm is better.

**Six career tracks**, led by Accounting & Finance and Business & Management — far and away the largest fields international students in Australia graduate into, not software. Each has a plausible CV with prior roles at real home-market employers (FPT, VNG, JD.com, HDFC Bank, Shopee) and a posting written the way Australian graduate ads actually read. **Every posting leaves requirements the CV does not cover**, so gap analysis has something real to find. Sample candidates span Indian, Chinese, Vietnamese and Nepali origins — six CVs from one country would quietly contradict the positioning.

## 10. Anticipated questions

**"Is the AI actually working?"**
The boundary is complete and the five prompts are written; the provider is bound to fixtures, and every fixture is badged "Awaiting AI" in the UI so nothing placeholder reads as real. Flipping `AI_COACH_PROVIDER=model` with a key is the whole handoff — and roughly 60% of what looks model-backed (the meter, the diff, delivery scoring, the entire sponsorship drill) is deterministic and already real.

**"Why not just use one big model for everything?"**
Latency. A model in the sub-second path cannot keep up with speech. And on STAR staging specifically, the expensive models were measurably no better than the cheap one — the fix was a deterministic prior, not a bigger model.

**"Isn't detecting someone's first language from their speech problematic?"**
Yes, which is why it is not done. Patterns in text are detected; the speaker is never classified. First language is asked, optional, and never inferred — and none of it is scored.

**"Why build camera analysis when the spec cut it?"**
It was built as a mirror, not a mark — it never enters any score, it classifies no emotion, and it measures gaze *steadiness* rather than gaze *direction*, because eye contact is a cultural norm and scoring it would punish the exact behaviour this product exists to help someone navigate.

**"What's not real?"**
The employer sponsorship data is unverified sample data — flagged as such in the API and shown with a red warning in the UI. The subclass 485 duration table needs verifying against Home Affairs. Both are stated in the product rather than hidden.
